# Business Sales Analytics Dashboard

## 📊 Project Overview
An end-to-end business analytics and business intelligence project using Python, SQL, Power BI, DAX, Power Query and Excel concepts to analyze sales, customers, products, regions and profitability.

## 🎯 Objectives
- Analyze sales and revenue performance
- Identify top products and customers
- Compare regional and category performance
- Track profit and margins
- Build interactive Power BI dashboards
- Demonstrate an end-to-end analytics workflow

## 🛠️ Tech Stack
- Power BI
- DAX
- Power Query
- Python
- Pandas
- SQL
- Excel
- GitHub

## 📁 Project Structure
```text
data/             → Sales dataset
python/            → Python analysis
sql/               → SQL business queries
powerbi/           → Power BI dashboard and instructions
screenshots/       → Dashboard screenshots
documentation/     → Project documentation
```

## 📊 Dashboard Pages
1. Executive Overview
2. Sales Analysis
3. Customer Analysis
4. Profitability Analysis

## 🧮 Core KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Average Order Value
- Sales Growth

## 🔄 Workflow
Raw Data → Cleaning & Transformation → Python EDA → SQL Analysis → DAX → Power BI Dashboard → Business Insights

## 🚀 How to Use
1. Open `data/sales_data.csv`.
2. Run `python/sales_analysis.py` from the Python folder or adapt it to Jupyter/Colab.
3. Import the CSV into Power BI Desktop.
4. Create the recommended DAX measures in `powerbi/README.md`.
5. Build the four dashboard pages.
6. Save the `.pbix` file inside `powerbi/`.
7. Add screenshots of the completed dashboard to `screenshots/`.
